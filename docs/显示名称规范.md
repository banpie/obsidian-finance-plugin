# 显示名称规范

投资与借贷名称使用统一的展示函数，适用于报表及下钻、币种卡片及详情、账户树和账户详情标题。

- 主名称不使用 `【】`，名称段用 `-` 分隔；份额类别中的空格保留，例如 `A HKD Acc`。
- 投资主名称去掉明确的购买渠道前缀，如余利宝、支付宝、富途。只移除独立的前缀词，不移除发行方名称中的同名文字。未知前缀保留。
- 保留产品名称、代码、发行方、币种、份额、期限，以及再次持有的日期说明；标会、投顾等类型说明保留。
- 借贷标题保留往来对象和用途，例如 `小林-分红转借款-202401-10W`。原始日期、金额说明不作为当前余额解读，也不自动删改。
- 原始账户中的技术类型与内部编号不放在主标题中。账户编号和渠道放在次要账户参考信息中，避免同名产品或往来被混淆。代码和原始科目可在表格、悬停提示或详情中查看。

这是一项展示规则，不是 Beancount 科目迁移。原始账户路径、商品代码、元数据、金额与查询参数不变，不按显示名称合并持仓或往来；名称编辑仍保存用户输入的原文。搜索同时支持原始名称、渠道和新显示名称。

规则入口：`src/utils/displayNames.ts`。渠道必须明确列入集合，禁止按任意第一个词猜测、按子字符串全局删除或根据相似名称归并金融对象。
