# 金额展示规范

财务界面共用 `Amount` 与 `InventoryAmounts` 组件，使用 `transactionDisplay` 的方向和格式化规则。展示转换不修改账本、原始 CSV 或编辑表单。

- 收入、支出及项目收支：收入为正，支出为负；退回收入为负，支出退款为正。对收入和支出科目的原始记账数量取反，不使用绝对值，因此保留退款、冲减和反向余额。
- 资产、账户余额与净资产：保留真实余额方向。负债报表内部若存储欠款正数金额，展示时取反，与账户页的负债余额一致；反向负债为正。资产和负债明细都保留非零负余额。
- 借贷：应收为正，应付为负；内部净额计算继续为应收减去应付金额。借贷的方向、状态和实际科目相互独立，不因为展示颜色重分类。
- 正数带 `+` 并使用绿色，负数带 `-` 并使用红色，零值不带正负号并使用中性色。投资盈亏继续遵守既有的盈亏配色设置，但必须显示正负号。
- 法币按币种精度显示；非零微小金额保留有效数字，不能变成带符号的零。商品数量保留精度；不同币种分别展示。查询金额不能先按账本最常用小数位取整而丢失分、厘等小额金额。
- 流水主金额与交易页方向一致，悬停显示原始分录金额，编辑事件继续使用未经修改的分录对象。余额核对使用对应账户的展示方向。
- 分类图的扇区面积使用绝对值，悬停金额保留符号；趋势图的数据和悬停金额都使用展示方向。分类配色用于区分类别，金额配色用于区分正负。
- 价格、汇率、单位成本、预算额度和进度属于参考值或目标值，保留自身语义，不用收支方向改写。

计划交易先从模板的收支分录或资产变动确定方向；纯同币种内部转账或方向不明时，仅以中性色显示参考额度，不把旧的正数缓存金额当作收入。生成交易继续使用原始模板。
