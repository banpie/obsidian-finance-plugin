# 多语言支持

设置「基本偏好 → 界面语言」提供三个选项：跟随 Obsidian、简体中文、English。选择保存在插件设置的 `language` 字段，默认跟随 Obsidian；中文界面使用简体中文，其他未支持的语言回退英语。切换后页面文字和图表更新，无需重启。

翻译只改变显示：账户路径、币种代码、交易原文、文件路径、查询和筛选值保持原样。查询引擎返回的原始错误与用户自行命名的内容可能保留原语言。

翻译真源位于 `src/i18n/en.ts` 与 `src/i18n/zh-CN.ts`，采用来源短语作为消息 ID。新增语言时增加词典，并扩展 `Locale`、`LanguagePreference`、`resolveLocale` 和设置中的语言选择入口。

- 原生设置、命令和提示使用 `t(message, values)`。
- Svelte 使用订阅式 `$tr(message, values)`；包含翻译的选项数组使用 `$:`，保留原有 `value`。
- 动态文本使用 `{0}`、`{1}` 等参数占位，避免逐词拼接，不翻译参数中的账本数据。
- 图表通过 `localizeChartConfig` 复制显示字段，保留数值、回调与下钻键。
- 运行 `npm test`、`npm run build`、`npm run lint`。测试检查语言解析、即时订阅、词典占位、图表数据不变，以及真实 Svelte 组件编译和选项值。
